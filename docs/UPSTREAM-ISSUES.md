# Relationship to upstream issues

These entries describe implementation coverage. The complete update has a general in-game confirmation from an earlier build.

| Area | Change |
| --- | --- |
| Cloning (#92, #93, #94) | Zero accident rate permits creation, an attempt or additional birth pays once, and the launchpad uses the surface restriction. |
| KuddleShack (#25, #34, #35, #40) | Off pauses progress and missing pairs stop it. Status, countdown, pair details and blockers are shown. Saved checkpoints credit elapsed game time. Births still require player action. |
| Settings (#54) | Unique names avoid collisions and recognised legacy pages migrate on load. |
| KloneKabin and Academy feedback (#43, #44) | Failure messages and editor recipes improve feedback. A persistent eligible-trainee count is outside the update. |
| Inheritance (#21) | Optional clones inherit a selected source's stock attributes, appearance, profession and XP. KuddleShack offspring retain their own creation rules. |

MKS profession and Akademy support are optional. The USI Life Support request (#83) is separate.
